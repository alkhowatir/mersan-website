# العربة الماهرة (Skilled Cart) — Static Website

الموقع الرسمي لمؤسسة **العربة الماهرة** المتخصصة في بيع وتأجير وصيانة عربات الجولف (Golf Carts) في المملكة العربية السعودية.

تمت إعادة كتابة وتحويل الموقع بالكامل من بيئة PHP / WordPress / Elementor السابقة إلى موقع ويب ثابت وقياسي فائق السرعة وخفيف الوزن مبني باستخدام **HTML5 / CSS3 / Vanilla JavaScript** بدون أي اعتماديات أو قواعد بيانات أو خطوات بناء (No build step).

---

## مميزات البنية الحالية

- **أداء فائق وخفة استثنائية:** تم استبدال أكثر من 30 ملف CSS ومكتبات Elementor بملف تنسيق موحد ونظيف `assets/css/style.css` وملف تفاعلي جافاسكريبت نقي `assets/js/main.js`.
- **دعم كامل للغة العربية (RTL):** تصميم مخصص لاتجاه اليمين لليسار مع المحاذاة الدقيقة للنصوص والأرقام والأيقونات (`lang="ar"` و `dir="rtl"`).
- **تصميم وهوية مطابقة للأصل:** الحفاظ التام على ألوان الهوية المؤسسية (الكحلي `#212d45`، المرجاني `#d97d68`)، والخطوط (`Cairo` و `Montserrat` و `Roboto`)، وجميع الصور والأصول الأصلية.
- **تفاعلية متكاملة بدون مكتبات خارجية:**
  - قائمة تنقل للجوال متجاوبة (Mobile Drawer) مع دعم إمكانية الوصول و زر الهروب (ESC).
  - قائمة أسئلة شائعة تفاعلية (FAQ Accordion) تعمل بسلاسة.
  - نموذج طلب الخدمة مع معالجة وإشعارات فورية وإمكانية الإرسال المباشر عبر واتساب.
- **تهيئة محركات البحث (SEO):** وسوم الميتا الدقيقة، و Open Graph، و Twitter Cards، وبيانات Schema.org المنظمة (JSON-LD)، وملف `sitemap.xml` و `robots.txt`.

## التشغيل والتطوير المحلي (Local Development)

الموقع ثابت بنسبة 100% ولا يتطلب تثبيت حزم أو بيئة تشغيل خاصة. يمكنك تشغيل خادم محلي بأي أداة متوفرة لديك:

### باستخدام Python:
```powershell
python -m http.server 8000
```

### باستخدام PHP:
```powershell
php -S 127.0.0.1:8000
```

### باستخدام Node.js:
```powershell
npx serve .
```

ثم افتح المتصفح على: `http://127.0.0.1:8000/`

## النشر والاستضافة (Deployment)

الموقع جاهز للنشر على أي منصة استضافة مواقع ثابتة أو خوادم تقليدية:

1. **الاستضافة التقليدية (Apache / cPanel):**
   - ارفع جميع الملفات مباشرة إلى مجلد `public_html` أو الجذر.
   - ملف `.htaccess` المرفق مهيأ مسبقاً لتوجيه الروابط وتفعيل التخزين المؤقت وضغط الملفات وحماية المجلدات الخاصة.
2. **الاستضافة السحابية الثابتة (Cloudflare Pages / GitHub Pages / Vercel / Netlify):**
   - ارفع المستودع مباشرة؛ لا توجد أي أوامر بناء (Build Command: فارغ، Output Directory: `.`).

## هيكل المجلدات والملفات (Directory Structure)

```text
skilledcart/
├── index.html              # الصفحة الرئيسية (Hero, احصائيات, خدمات, أسئلة شائعة, طلب خدمة)
├── about/
│   └── index.html          # صفحة من نحن (رؤية، رسالة، معايير الجودة)
├── services/
│   └── index.html          # صفحة خدماتنا (بيع، تأجير، صيانة، قطاعات الاستخدام)
├── projects/
│   └── index.html          # صفحة مشاريعنا (معرض المشاريع وشركاء النجاح)
├── contact-us/
│   └── index.html          # صفحة تواصل معنا (بيانات الاتصال وخريطة Google Maps التفاعلية)
├── 404.html                # صفحة الخطأ المخصصة 404 Not Found
├── sitemap.xml             # خريطة الموقع لمحركات البحث
├── robots.txt              # توجيهات عناكب البحث
├── .htaccess               # إعدادات خادم Apache (ضغط، تخزين مؤقت، توجيه 404)
├── assets/
│   ├── css/
│   │   └── style.css       # ملف التنسيقات الموحد والخفيف للموقع بالكامل
│   ├── js/
│   │   └── main.js         # كود جافاسكريبت النقي للتنقل والتفاعلات
│   ├── images/             # جميع صور ورسومات الموقع الأصلية
│   └── fonts/              # خطوط الموقع المحلية
└── _legacy_php/            # أرشيف ملفات PHP السابقة للمرجعية وحفظ السجل
```
