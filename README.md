## التقنيات المستخدمة (Technology Stack)

- **HTML5:** هيكلة دلالية متوافقة مع اتجاه RTL ووسوم SEO و Open Graph و Twitter Cards وبيانات Schema.org المنظمة (`JSON-LD`).
- **CSS3:** ملف تنسيقات موحّد ([assets/css/style.css](assets/css/style.css)) يعتمد على المتغيرات (`:root` CSS Custom Properties)، و Flexbox / CSS Grid، وتنسيقات متجاوبة لجميع المقاسات.
- **Vanilla JavaScript:** ملف تفاعلات خفيف بدون مكتبات خارجية ([assets/js/main.js](assets/js/main.js)) لإدارة قائمة الجوال، والأسئلة الشائعة التفاعلية (Accordion)، والتحقق من نموذج طلب الخدمة وتجهيز الإرسال.
- **Font Awesome (6.5.1 via CDN):** للأيقونات الواجهية في البطاقات وقوائم التواصل.
- **Apache Configuration:** إعدادات `.htaccess` لإعادة التوجيه إلى HTTPS، وضغط الملفات، والتخزين المؤقت، وتوجيه صفحة الخطأ `404.html`.

## الصفحات الرئيسية وغرض كل صفحة (Main Pages)

1. **الصفحة الرئيسية (`index.html`):** عرض الرسالة الترحيبية، خطوات العمل الأربع (`01`–`04`)، نبذة تعريفية عن مرسان، بطاقات الخدمات الرئيسية الثلاث، رسالة الجودة والمنهجية، خطوات التنفيذ، الأسئلة الشائعة التفاعلية، ونموذج طلب الخدمة.
2. **من نحن (`about/index.html`):** تعريف بمرسان المرافق، ركائز العمل (`وضوح`، `اهتمام`، `مرونة`)، والقيم التشغيلية.
3. **خدماتنا (`services/index.html`):** استعراض الخدمات الأساسية (`خدمات النظافة`، `مساندة تشغيل المرافق`، `خدمات مساندة`) ومراحل العمل الثلاث من الطلب حتى المتابعة.
4. **منهجيتنا في العمل (`projects/index.html`):** عرض مرئي لخطوات التنفيذ الأربع في مرسان المرافق.
5. **تواصل معنا (`contact-us/index.html`):** قنوات الاتصال المباشر (الهاتف، البريد الإلكتروني، واتساب)، ملخص خطوات الاستشارة، ونموذج طلب عرض السعر.
6. **صفحة 404 (`404.html`):** صفحة خطأ مخصصة بالهوية الرسمية مع رابط للعودة إلى الرئيسية.

## متطلبات التشغيل المحلي (Installation & Local Run)

لا يتطلب المشروع تثبيت أي حزم أو اعتماديات برمجية. يكفي وجود خادم ملفات ثابتة بسيط (مثل Python أو PHP أو Node.js).

### التشغيل باستخدام Python

```bash
python -m http.server 8000 --bind 127.0.0.1
```

### التشغيل باستخدام PHP

```bash
php -S 127.0.0.1:8000
```

### التشغيل باستخدام Node.js

```bash
npx serve .
```

بعد تشغيل أحد الأوامر السابقة من جذر المشروع، افتح المتصفح على:

```text
http://127.0.0.1:8000/
```

## النشر والاستضافة (Deployment)

1. **الاستضافة التقليدية (Hostinger / cPanel / Apache):**
   - ارفع جميع محتويات الجذر مباشرة إلى مجلد `public_html`.
   - يعمل ملف `.htaccess` تلقائياً على تفعيل HTTPS، ضغط الملفات، التخزين المؤقت للأصول الثابتة، وتوجيه صفحة الخطأ `404.html`.
2. **الاستضافة السحابية الثابتة (Cloudflare Pages / Netlify / Vercel / GitHub Pages):**
   - اربط المستودع مباشرة بدون أي أوامر بناء (`Build Command`: فارغ، `Output Directory`: `.`).
3. **إعداد نموذج الطلب (Web3Forms):**
   - يحتوي الحقل المخفي `access_key` في `index.html` و `contact-us/index.html` على قيمة مبدئية (`PENDING_MERSAN_WEB3FORMS_KEY`). عند توفر مفتاح Web3Forms الخاص بمرسان يتم استبداله مباشرة، وحتى ذلك الحين يقوم ملف `assets/js/main.js` بالتحقق من الحقول وتجهيز روابط إرسال مباشر عبر واتساب والبريد الإلكتروني.
